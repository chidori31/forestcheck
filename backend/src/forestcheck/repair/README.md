# repair

RecommendationEngine формирует SuggestionV2, объяснение и ProposedPatch только
после проверки копии записи. Источники: совместимые арифметические правила,
применимые таблицы, существующие условные модели и групповой train-reference.
Отсутствие основания, конфликт и подозрительные входы дают явный отказ/ручной разбор.

Raw/source неизменны; verify_patch проверяет привязку и целостность, ничего не
применяет. Review отделяет подтверждение ошибки от принятия значения. CLI
recommendations_local.py выполняет замороженный dev-эксперимент; подробности
и ограничения — docs/recommendations.md. На этапе 8 отдельный workflow API создаёт
новую версию из подтверждённых patch после повторной проверки. Этот модуль
по-прежнему ничего не применяет и не изменяет источники.
