# ml

Реализованы train-only условные медианы/MAD, CatBoost MultiQuantile,
IsolationForest, групповой OOF, калибровка и доверенные локальные артефакты.
Запуск: scripts/ml_local.py; методика и ограничения: docs/ml_methodology.md.
Прогноз восстанавливает наблюдение, не подтверждает истинность значения.
Реального классификатора ошибок, автоматического исправления и обучения
по экспертной обратной связи пока нет. Внутренний holdout уже оценён на этапе 10;
он не считается нетронутым и не используется для новой настройки в этой ревизии.
Разметка хранится отдельно от признаков. GPU не требуется каркасу.
