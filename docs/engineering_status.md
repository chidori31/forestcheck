## Изменения и доказательства

- Обязательные поля и категории; иерархия выдел → ярус → элементы, отдельный
  подрост. Неполные/противоречивые связи не доказывают отсутствие дочерней записи.
- Полные связки сравниваются с кратностью, namespace и периодом, затем содержательно
  после хеша. Неактивный план сохраняет source IDs; исключения не применяются.
- Высоты привязываются к файлу/листу/позиции и явному основанию. Пока соответствие
  не известно, нет числового кандидата; никакого масштаба ×10 или вывода по дробности.
- Строгая совместимость сумм запасов, отдельные кандидаты роста и импорт будущих
  экспертных меток. Метки не входят в признаки и не применяют исправления.
- Локальный XLSX-review проверяет snapshot/split/cohort hashes и допущенные UUID,
  сохраняет сведения о пропущенных детях. API/UI остаётся CSV — это ограничение MVP.

Независимое ревью выявило и регрессионные тесты закрыли: отсутствие привязки высот
к файлу/листу, смешение пространств ID, недопустимое дерево, противоречивые корни
и связи снимков, недостаточную привязку cohort к frozen источнику, а также потерю
признака неполноты при исключении ребёнка из поднабора. Последнее ревью также
выявило утечку через подтверждённую копию объекта, использованного для настройки;
14 регрессий воспроизвели её. Исправлена транзитивная/двусторонняя проверка exposure
по связям record/parent/group/copy; после этого выполнен новый полный прогон.

Создан локальный Git и по прямому запросу владельца — приватный GitHub repository.
Отправляются только явно отобранные код, синтетика, locks, лицензии и безопасные

разрешением передавать туда конкурсные материалы.

Начальная Git whitespace-проверка сообщила CRLF как trailing whitespace;
локальная настройка `core.whitespace=cr-at-eol` учитывает Windows line endings.
Лицензионные тексты и историю ради форматирования не переписывали.

Для промежуточного показа можно использовать проверенный синтетический путь.

критерий дублей, независимые экспертные ответы и точный формат сдачи. Интеграция
