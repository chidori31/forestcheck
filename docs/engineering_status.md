## Совместимость и демонстрация

Старые CSV/Record/ML контракты не менялись. Новые workbook UUID/mapping не подставляются
в старую модель автоматически. Новое реальное обучение, новая итоговая оценка и
настройка по holdout — NOT_RUN. Существующий holdout уже был открыт ранее и не
называется независимым заново. Нет реальной экспертной оценки/подтверждённой экономии.

E2E проверил реальный API/worker, synthetic upload, finding/evidence, принятие и
отклонение, создание версии, JSON-отчёт и XLSX-экспорт. Снимки 1440×900 и 1280×720
сохранены из браузерного прогона; малый экран осмотрен. Резерв обозначен как статический.

## Git и остающиеся ограничения

Создан локальный Git и по прямому запросу владельца — приватный GitHub repository.
Отправляются только явно отобранные код, синтетика, locks, лицензии и безопасные
инструкции. Исторические отчёты с реальными производными, локальные настройки,
исходники и веса оставлены на машине. Приватность репозитория не считается
разрешением передавать туда конкурсные материалы.

Начальная Git whitespace-проверка сообщила CRLF как trailing whitespace;
локальная настройка `core.whitespace=cr-at-eol` учитывает Windows line endings.
Лицензионные тексты и историю ради форматирования не переписывали.

Для промежуточного показа можно использовать проверенный синтетический путь.
Для полной предметной сдачи остаются эталоны роста, семантика спорных полей,
критерий дублей, независимые экспертные ответы и точный формат сдачи. Интеграция
иерархического XLSX-снимка в API/UI — следующий самостоятельный инженерный этап;
текущий CLI-импорт не маскирует её отсутствие.
