Подобрали два открытых издания для обсуждения таблиц роста. Предлагаем начать
с пособия УГЛТУ: его приложения содержат несколько пород из
Вашего перечня. Региональная применимость ещё требует подтверждения; ДальНИИЛХ
оставляем дополнительным кандидатом по перечню пород.

Можно ли использовать конкретные таблицы из этих изданий для территории и пород
набора? Просим уточнить лесорастительный район, допустимые происхождение,
бонитет, тип леса, чистоту состава, смысл полноты и вид сравниваемого запаса.
Если они не подходят, достаточно названия рекомендуемого источника и нужной
таблицы. Разрешена ли интерполяция и каким пунктом методики она обоснована?

Для смешанных насаждений и иной полноты методика ещё не согласована, поэтому
значения не масштабируем и эталоны в действующий анализ не включаем.
Ссылка на инструкцию сейчас не открылась; если возможно, просим доступную копию
с реквизитами и редакцией. Подробная карточка проверки —
[growth_reference_candidates.md](growth_reference_candidates.md).
