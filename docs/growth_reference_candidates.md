# Кандидаты таблиц роста: экспертная итерация

Проверка открытых источников: 12.10.2026. Все перечисленные материалы имеют
статус **found**. Ни один не допущен в `GrowthTableRegistry`; результат реального
сравнения остаётся `unavailable_reference`. Подбор ориентирован на перечень пород
эксперта. Для первого обсуждения предлагается C2; C1 — дополнительный кандидат,
без заявления о совпадении с наблюдаемым регионом. Региональная применимость
требует отдельного подтверждения. Анализ фактического контекста хранится приватно.
Пригодность для конкретной территории не заявляется. Holdout, реальные строки,
региональные коды и частные схемы для внешнего поиска не использовались.

## Доступность и ограничения проверки

Оба PDF доступны как разобранный текст страниц через веб-инструмент: прочитаны
табличные заголовки и численные строки, не только поисковые фрагменты.
Снимки страниц вернули `Internal Error`; непосредственная загрузка дала
HTTP 429 для C1 и HTTP 502 для C2. Визуальная сверка **NOT_RUN**, локальные
бинарные копии и их SHA-256 не получены. Перед оцифровкой необходимы визуальная
сверка, стабильная копия с хешем и проверка прав включения. Полные таблицы
не включены в продукт; открытая ссылка не является лицензией.

Интерполяция ни для C1, ни для C2 здесь не разрешена. Экстраполяция, соседний
регион, автоматическое масштабирование по полноте/составу не применяются.
Нормальное полное насаждение не объявляется моделью произвольного смешанного
леса; даже наличие единицы 1,0 не доказывает чистый состав.

## Статусы и контракт

`growth/candidates.py` добавляет отдельные строгие неизменяемые sidecars
`GrowthReferenceCandidate` / `GrowthCandidateRegistry`, schema_version 1.0.
Источник, точное место таблицы, просмотренность, отдельные purity/fullness,
неизвестные и статус сохраняются без численных точек эталона.

- `found`: найден источник; сведения могут быть неполными.
- `applicability_checked`: предоставлены основание проверки, хеш проверенного
  контекста и закрытый перечень неизвестных; текст таблицы просмотрен.
- `expert_confirmed`: дополнительно присутствует отдельное основание
  подтверждения специалистом.

Валидатор проверяет согласованность заявлений и наличие evidence, не истинность
мнения специалиста. Ни один статус не выполняет регистрацию в рабочем реестре.
Действующий Growth V1 по-прежнему не имеет отдельного проверенного допуска
чистоты/полноты. После выбора источника потребуется самостоятельная проверка
typed applicability и совместимости перед созданием `GrowthTable`.

## Указанная экспертом инструкция

[Ссылка эксперта](https://docs.cntd.ru/document/351878696) при двух прямых
открытиях вернула `Internal Error`. Поисковая карточка указывает приказ
Минприроды России от 05.08.2022 №510, регистрация 30.09.2022 №70328;
это идентификация документа, а не проверка полной редакции.
Подтверждённая идентичная официальная копия в этой проверке не получена.
Статус нормативного текста — `unavailable_reference`; редакция и применимость
к архивному наблюдению не установлены, правила из него не извлекались.
Прямые пояснения эксперта имеют самостоятельное происхождение и не выдаются
за процитированные пункты этой инструкции.
