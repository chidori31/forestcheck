# Промежуточная демонстрация: основной и резервный сценарии

Только самостоятельно созданная синтетика. Предметная готовность PARTIAL.
Сценарий не подтверждает точность обнаружения ошибок на реальной разметке.
Рабочие 3 минуты — внутренний план, не дополнительный официальный слот.

## Подготовка

Установка — README. Затем `python scripts/release.py build` через .venv.
Создать **новый пустой каталог вне репозитория**, задать серверные переменные:

```powershell
$env:FORESTCHECK_BACKEND_ROOT = Read-Host 'Новый приватный каталог для синтетического demo'
$env:FORESTCHECK_OPERATOR_TOKEN = [guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')
$env:FORESTCHECK_OPERATOR_ID = 'demo-operator'
.venv\Scripts\python.exe scripts/release.py demo
```

В UI http://127.0.0.1:4173 указать API http://127.0.0.1:8000 и токен из локального
окружения; не включать токен в адрес, скриншот или демонстрируемый терминал.
Проверить маркировку «Синтетические данные». При ошибке не подменять real-данные demo.

## Живой путь

1. 0:00–0:35 — загрузить frontend/public/demo/synthetic.csv и mapping.json;
   подтвердить позиции, единицы и уровень записи.
2. 0:35–1:05 — запустить анализ, дождаться worker, открыть первое замечание.
   Это отсутствие значения и арифметическое основание на синтетике, не доказательство
   статистической аномалии/лесотаксационной ошибки в настоящем наборе.
3. 1:05–1:45 — показать исходную ячейку, основание, предлагаемое значение и
   ограничения. Нет реального эталона — так и написано. Показать раздельные решения
   «Наличие ошибки» и «Решение по предложению».
4. 1:45–2:20 — сохранить одно принятие, другое предложение отклонить. Сохранение
   рассмотрения само по себе не исправляет исходник.
5. 2:20–3:00 — выгрузить отчёт; отдельным действием создать версию из подтверждённых
   решений и выгрузить XLSX. Показать неизменность оригинала.

Путь автоматизирован в frontend/e2e/workflow.spec.ts, с настоящими API/worker и
экспортом. Конфликт версий, сетевой сбой и неподдерживаемая загрузка проверяются
отдельными E2E. Неподтверждённые метрики не демонстрируются.

## Резерв

Запустить `npm run test:e2e` из frontend заранее. Скриншоты двух разрешений,
report.json и corrected.xlsx сохраняются в work/ui-e2e. Безопасный резервный
комплект копируется в outputs/ForestCheck-interim-demo с manifest SHA-256 и
идентификатором сборки. Он содержит только синтетические результаты.

При сбое честно сказать: «Это сохранённый результат проверенного синтетического
прогона указанной сборки, сейчас живой расчёт не выполняется». Показать снимок
evidence, отчёт и экспорт. Не выдавать статичный результат за текущий запрос.
При расхождении версии повторить тест и пересоздать комплект, не редактировать данные.
# Уточнение эксперта, 12.10.2026

Можно готовить выступление в собственном шаблоне; окончательные критерии ещё
согласовываются. Обещанные размеченные примеры пока не получены. Новый локальный
XLSX-анализ иерархии/полных связок показывать как отдельную инженерную проверку,
не как уже подключённую функцию CSV-интерфейса. Таблицы роста — кандидаты,
не утверждённый эталон. Старые метрики моделей не переносятся на новую семантику.

Основной и резервный сценарии ниже сохраняются; резервные снимки должны иметь
явную дату/версию и подпись «Синтетические данные», без имитации живого расчёта.
