# Структурированный XLSX-импорт

Рабочий адаптер `forestcheck.ingest.xlsx_import` и CLI `scripts/import_xlsx_local.py`.
Версия pipeline: `xlsx-import-1.0.1`. Это самостоятельный путь импорта в приватные
снимки; окно загрузки API/UI пока принимает CSV. XLSX не выдаётся за подключённый
к API формат. Существующие CSV-наборы, модели и frozen split не изменяются.

## Контракт

`WorkbookMapping` schema_version=1.0 отвергает неизвестные поля/версии. Mapping
содержит полный перечень листов, позиционные ColumnMapping, уровень записи,
основание зерна и parent_sheet. Одинаковые заголовки не объединяются; внутренние
имена уникальны по позиции. Пример mapping — только синтетика в configs/.

Основная политика `composite` связывает territory/compartment/stand. Отдельная
явная политика `workbook_local` допускает локальный идентификатор внутри одного
снимка маленького примера; не создаёт отсутствующую географию и не используется
для межкнижных связей. Несовместимые области ключа отвергаются.

Каждая запись имеет свой UUID, sheet/row/column и artifact_id исходника.
Снимок содержит отдельный Parquet на каждый лист, relations.jsonl, cells.jsonl,
quarantine.jsonl, mapping, metadata, report и manifest с SHA-256. Relations —
отдельные ссылки, не join с размножением строк. Неоднозначный родитель не выбирается
произвольно. Формулы не вычисляются, кеш не становится наблюдением; выражение,
кеш, тип и стиль сохраняются отдельно. Excel serial date не становится возрастом
или датой наблюдения автоматически. Записи без достаточной идентичности сохраняются
в quarantine с raw/координатами, включая разреженные строки в конце листа.

Все физические строки после заголовка учитываются в accepted + quarantine;
несуществующие XML-строки не синтезируются по dimension. Ничего не исключается.
Повтор source SHA + mapping SHA + pipeline возвращает тот же снимок после проверки
контрольных сумм. Изменение версии даёт новый снимок; незавершённые .incomplete
не считаются результатом. Новые снимки не подключаются к обучению автоматически.

## Диагностика

- `exact_rows`: совпадают значения, типы и формулы всех позиционных ячеек внутри
  листа; оформление не является частью равенства. Это не доказательство копии события.
- `candidate_identifier_collisions`: повторяются доступные кандидатные ключи.
- `allowed_cross_level_repetitions`: ожидаемая структурная кратность дочерних строк
  при единственном родителе, не доказательство корректности содержания.
- `conflicting_records`: у кандидатного родительского ключа разные представления;
  невозможно выбрать правильное автоматически.
- `ambiguous_repetitions`: необходимы зерно, время и экспертный критерий.

Категории могут пересекаться. Их количества нельзя складывать как число ошибок.
Диагностика не создаёт экспертные метки, не удаляет данные и не меняет split.

## Локальный запуск (PowerShell)

```powershell
.venv\Scripts\python.exe scripts/import_xlsx_local.py --config configs/local.xlsx.json
```

Конфигурация по образцу `configs/xlsx.example.json`: настоящий source_dir,
private_dir и mapping_file задаёт владелец локально. Mapping — в приватном корне,
выходы — `private_dir/xlsx_snapshots/workbook_imports/<UUID>`.
Для ZIP обязательно точное archive_member: извлекается только выбранный XLSX
в `private_dir/xlsx_sources`, с хешами контейнера/члена и provenance, без запуска.
stdout: только XLSX_IMPORT_STARTED/COMPLETE/FAILED/INTERRUPTED, без содержимого/путей.

Ограничения: локальные обычные файлы, без symlink/reparse; книга ≤512 MiB,
XML-член ≤512 MiB, суммарное распакованное содержимое ≤1 GiB, ≤4096 ZIP-членов,
коэффициент сжатия ≤1000, ≤2048 колонок, ограниченные XML-метаданные/shared strings.
ZIP-источник и выбранный XLSX-член ≤128 MiB. Макросы, внешние связи и embedded
objects отвергаются. DTD/entities запрещены. Это ограничения MVP, не обещание
поддержки любых Excel-документов. Исходники открываются только для чтения.

Совместимость: старые CSV mapping/schema/Record не изменены. Новый workbook UUID
не подставляется в прежнюю модель; для его анализа нужен отдельно допущенный
профиль. API-регистрация и визуализация связей XLSX — ещё не реализованы.
